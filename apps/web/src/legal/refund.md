## 1. 计费方式
- Pro 方案每月 20 美元，价格已含税。
- 按月计费，每个计费周期开始时扣款，到期自动续费。

## 2. 取消订阅
- 你可以随时取消。取消后不再自动续费。
- 已支付的当前计费周期结束前，你仍可正常使用；周期结束后服务降级为未订阅状态。

## 3. 退款
- 取消订阅不会对当前计费周期按天退款，因为你在周期结束前仍可使用。
- 以下情况可申请退款：
  1. 重复扣款或扣款金额错误：全额退还多扣部分；
  2. 取消后仍被续费扣款：退还该次续费；
  3. 因我们的原因导致服务在计费周期内长时间无法使用：【待填：退款比例或计算方式】；
  4. 法律规定的其他情形（例如适用的消费者撤回权）。
- 申请期限：扣款后【待填：天数】天内，发邮件至【待填：联系邮箱】，注明账号和扣款记录。
- 退款原路退回，到账时间取决于支付渠道。

## 4. 不予退款的情形
- 第三方费用（模型 API 调用费、GitHub 费用等）由第三方收取，不在本政策退款范围内，请按第三方规则处理。
- 因违反《服务条款》被终止服务的，【待填：是否退款】。

## 5. 在线支付开通前
在线支付开通前，本服务不收取任何费用，因此不涉及退款。
