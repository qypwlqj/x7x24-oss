## 1. 我们收集哪些信息
| 类别 | 内容 | 用途 |
|---|---|---|
| 账号信息 | GitHub 登录名、GitHub 用户 ID、头像、你所在的工作区和角色 | 登录、权限管理 |
| GitHub 授权信息 | 你授权的访问令牌、GitHub App 安装信息、可访问的仓库列表 | 读取和（在执行模式下）改动你授权的仓库 |
| 对话与需求内容 | 你在对话中输入的内容、需求草稿、操作确认记录 | 理解需求、生成计划与改动 |
| 仓库代码 | 为完成任务所需读取的文件内容、差异（diff）、CI 日志片段 | 生成代码、测试、审查 |
| 等待名单邮箱 | 你在定价页主动填写的邮箱、提交时间与同意时间 | 付费功能开通时与你联系 |
| 日志与审计记录 | 操作审计、错误日志、模型调用用量与估算费用 | 安全、排错、计费与预算控制 |

我们不在等待名单中记录你的 IP 地址；为防止滥用，服务器会在内存中短暂使用请求来源地址进行限流，不写入数据库。服务器访问日志可能包含 IP 地址，保存期限见第 5 节。

## 2. 我们如何使用
仅用于提供和改进本服务、保障安全、履行法律义务，以及在你加入等待名单时与你联系。我们不会出售你的个人信息，也不会把你的代码用于训练模型。

| GitHub | 仓库操作请求、授权令牌 | 用于登录与仓库读写 |
| 云服务器提供商【待填：云服务商名称及服务器所在地区】 | 本服务存储的全部数据 | 托管与运行 |
| 邮件服务商（如启用通知） | 通知摘要与收件地址 | 仅在工作区配置了邮件通知时 |

法律要求或为保护我们与用户的合法权益时，我们可能依法披露信息。
