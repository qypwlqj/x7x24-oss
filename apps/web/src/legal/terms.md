## 1. 服务说明
7x24 Agent（下称"本服务"）是一个软件交付辅助工具。你可以在对话中创建产品线、项目和需求，绑定 GitHub 仓库，并由自动化流程生成计划、代码改动、测试与审查结果，交由你确认和验收。

- 会改动数据的操作会先给出确认卡，经你确认后才执行。
- 本服务可能运行在"观察（演练）模式"：此时只生成计划和预览，不会对你的仓库提交改动。是否切换为执行模式由你的工作区管理员决定。
- 自动生成的代码、审查意见和其他结果可能存在错误。你应自行审阅、测试并对合并到仓库和上线的内容负责。

## 2. 账号与工作区
- 你需要使用 GitHub 账号登录。你应保管好自己的账号，并对账号下的操作负责。
- 工作区的所有者和管理员可以管理成员和角色；成员能看到其有权访问的工作区内容。

## 3. 你的内容
- 你提交的需求、对话内容，以及你授权访问的仓库代码，其权利归你或原权利人所有。
- 为提供本服务，你授权我们在必要范围内处理上述内容，包括将其发送给你或工作区配置的模型服务商（见《隐私政策》）。
- 你应确保有权将仓库内容提供给本服务及相关模型服务商处理。请勿在对话或任务中填写密码、密钥等凭据。

## 4. 第三方服务
本服务依赖第三方服务，例如 GitHub、模型服务商（如 DeepSeek）和云服务器提供商。第三方服务受其自身条款约束，其费用（如模型 API 调用费、GitHub 费用）由你按第三方的规则另行承担，不包含在本服务价格中。

- 退款规则见《退款政策》。
