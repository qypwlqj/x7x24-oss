### 2.1 侧栏顶部：＋ 新对话 + 2 个主菜单
- **＋ 新对话**（快捷键 Ctrl/⌘+K）：打开空白会话，只有一个输入框和一行灰色提示「描述需求，或让我建项目、邀请成员…」，没有场景按钮。当前选中了产品线（或其下的项目/任务）时，把该产品线记为会话上下文（`#/new?line=<id>`）。第一句话发出时才真正建会话（`#/s/<sessionId>`）。
  - 助手建了任务后，会话自动绑定该任务，界面转到 `#/t/<taskId>/chat`；之后这条会话只出现在树里该任务下面。
  - 建产品线/项目、邀请成员仍可在这里用一句话完成（先出确认卡）；也可从行 ⋯ 菜单进入（产品线 ⋯ →「新建项目」「邀请成员」，会打开带预填句子的新对话）。
  - 只读成员也能新开对话提问、查进度，但没有任何操作按钮（确认卡不可执行、草稿不可编辑）。
- 原「指挥台」主菜单、首页（问候语 + 需求/产品线与项目/成员/查询 按钮网格）和「指令记录」列表都已取消。
- **总览**：原总览看板，默认工作区范围；在项目/产品线页签里有同一组件的范围版。
- **待我处理**：审批、阻塞、等我回复、超预算的聚合（原“任务”页按我过滤 + 通知里需要动作的那部分）。
- **通知中心**：通过顶栏铃铛进入并显示未读数，侧栏不再重复展示入口。
- 原「任务」列表不再是一级菜单：放到项目页签“任务”，全工作区列表在“总览”里一个链接“全部任务 →”（`#/tasks` 保留）。

### 2.2 工作区树（嵌在主菜单下方，占剩余高度、独立滚动）
- 产品线 → 项目 → 任务；顶部搜索、＋（新建产品线/项目，按权限）、⋯（分组方式：按产品线/只看我参与的/隐藏已完成）。
- 每个项目默认显示阻塞/等我 + 最近 5 个任务，“显示更多”。折叠状态存 localStorage。
- 点产品线/项目/任务 → 内容区打开该对象（默认页签“会话”/“概览”）。M1 的中间树栏删除。
- 树下方「最近对话」（默认展开，记住折叠状态）：全部会话按最近更新取前 10 条，见 2.6。原「其他对话」并入这里。

### 2.3 行右侧小图标（最多 2 个 + 悬停出现 ⋯）
优先级从高到低，只显示最重要的 2 个，避免一行塞满：

| 图标 | 出现条件 | 用在 | 点击 |
|---|---|---|---|
| ⛔ blocked（红） | 任务阻塞/失败；项目上表示“下面有 N 个阻塞”带数字 | 任务、项目 | 打开任务会话并滚到阻塞卡 |
| ⏳ await-approval（黄） | 等我审批/等我回复（只对能处理的人显示） | 任务、项目 | 打开对应卡片 |
| ⛁ 预算 | ≥80% 显示百分比（黄），超额显示“超”（红），正常不显示 | 产品线、项目、任务 | 打开该对象的“预算”页签 |
| 状态点 | 没有上面任何图标时：绿=运行中、空心=未开始、旗=完成 | 任务 | — |
| ⋯（悬停/选中/触屏常显） | 始终 | 全部 | 行菜单（见 2.4） |

### 2.4 行 ⋯ 菜单
- **产品线**：新建项目、治理、预算、成员（按产品线筛选）、重命名/归档（B 类，跳管理页）。
- **项目**：新任务、预算、治理、仓库与上下文、成员、暂停/恢复项目、复制链接。
- **任务**：打开会话、任务详情、预算、暂停/继续、复制链接；放弃任务（管理员，二次确认，可恢复）。
- 只读成员只看到查看类条目；会改数据的条目对成员显示为“需管理员确认”（沿用确认卡机制）。

### 2.5 用户名弹出菜单（左下角）
个人：个人通知设置、主题。
工作区 · 管理（管理员可见，成员只见“成员列表（只读）”）：集成（GitHub 与仓库）、模型与流程、治理默认值、预算总额与变更历史、产品线与项目管理、成员与邀请、审计日志。
其它：切换工作区、平台管理（仅平台管理员）、退出登录。

### 2.6 对话归属与「最近对话」（PR「对话归属」）

问题：在新对话里让 agent 建了项目，点进项目后就找不到原来的对话。原因是建项目不绑定会话、「其他对话」默认收起、项目「会话」页签永远是空白输入框。

- **归属**（`chat_session.anchor_kind / anchor_id`，迁移 V48）：每个会话挂在最具体的对象上，**任务 > 项目 > 产品线 > 未归属**，只升不降。
  - 新建会话：带项目上下文 → 项目；带产品线 → 产品线；否则未归属。切换上下文（未绑定任务时）跟着改。
  - 对话里确认「新建产品线」→ 产品线；「新建项目」→ 项目（同时写 project_id / product_line_id）；建任务 / 任务会话 → 任务。
  - 标题兜底：没有草稿标题时用第一条消息前 20 个字。
- **侧栏「最近对话」**（工作区树下方）：
  ```
  ▾ 最近对话                12
    建官网项目   [项目·官网]  22:31  ⋯
    订单分页     [任务·…]     21:05  ⋯
    问下预算怎么算             昨天   ⋯
    查看全部 →
  ```
  ⋯ 菜单：打开所属对象 / 重命名 / 删除（删除权限同原来）。点任务会话进 `#/t/<id>/chat`，其余进 `#/s/<id>`。
- **`#/chats` 全部对话**：搜索标题 / 归属名，按 全部 / 任务 / 项目 / 产品线 / 未归属 筛选。
- **项目 / 产品线「对话」页签**：上面列出这个对象下的对话（产品线页包含下属项目的对话），下面「在此新对话」。树上项目行有 💬N 计数，点了进对话页签。
- **对话里的对象卡片**：建好的项目 / 产品线显示成卡片「打开项目 →」，链接带 `?from=s/<会话>`；对象页顶部据此显示「← 返回对话：标题」。
- API：`GET /api/chats?anchor=project:<id>|line:<id>|task:<id>|none`，返回带 `anchor_kind / anchor_id / anchor_name`；`PUT /api/chats/{id}/title` 改名。

## 6. 权限
- 前端按角色隐藏/锁定，**服务端照常校验**（现有 `WorkspaceFilter.requireMember` 与管理员校验不变）。
- **只读成员**：能新开对话提问；能看树、会话、所有页签（预算/治理只读，无“调整”按钮）；用户菜单只显示个人项 + 成员列表（只读）；⋯菜单只有查看类；“待我处理”只含通知。
- **成员**：可提需求、暂停/继续自己参与的任务；改预算/治理/仓库显示“需管理员确认”并生成确认卡。
- **管理员**：用户菜单的管理区全部可见；邀请管理员、转让所有者仍仅所有者。
- 预算调整、治理变更仍是 B 类（在页签里改，不在会话里通过自然语言直接改），会话只给跳转。
